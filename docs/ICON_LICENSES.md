packs (Iconify JSON `body` paths), not React icon component wrappers.

## Remix Icon — not included

Remix Icon License v1.0 (January 2026) permits use in apps and UI, but **prohibits**:

- Redistributing icons as a standalone / primary icon library product
- Using the icons to create a competing icon library or icon set

This product’s icon browser redistributes complete collections for selection, so
Remix Icon is omitted until legal review clears redistribution in this context.

Iconify’s `@iconify-json/ri` package metadata still lists Apache-2.0; the
upstream Remix Icon License v1.0 terms take precedence for the asset set.
